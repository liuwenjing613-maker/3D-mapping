显示方式与数据来源

点坐标、RGB、原生实例 ID 均来自两组最终 400 帧实际输出；没有重新分割。两边使用完全相同的点索引抽样，局部最多 18 万点，整场景最多 24 万点。页面抽样只影响显示，IoU 来自完整 R2 评价。

同场景按 GT 对应的主预测优先、再按几何重叠做一对一颜色配对，并尽量拉开邻近实例颜色；不同原生 ID 仍独立保留。颜色相同仅表示显示配对，不是证明身份相同。灰色是未分配点；勾选“淡化周围实例”时非目标关联 ID 也会淡化。GT 仅用于事后配色、定位和白点参照，不参与算法。

“关联 ID 的完整范围”展示两侧与该 GT 主要重叠的预测实例之并集，可检查它们是否延伸到其他物体。GT 白点是可评价 GT 参考表面，并非 TSDF 新增点。PLY 文件含实例色、RGB 和原生 instance_id 字段；文件和源数据均留在服务器。
