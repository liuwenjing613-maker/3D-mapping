## 效果与代价

四个修复版本整体AP50均为27.67%、F1均为52.38%、PQ均为34.46%，原始基线分别为28.44%、53.01%、34.87%。严格限制范围没有提高整体分数。

无门槛版mask24的v3 IoU由30.96%变为30.24%。在固定对应的GT4002表面上，新ID355参考支持从2884变为2823，旧ID52残留从36变为117。这说明严格恢复范围外标签会保留/恢复一部分旧错误归属。

该严格局部版的v3结构诊断重新出现残余合并与拆分标记，两个目标仍未达到IoU0.5。允许集合未扩张；没有为改善这些指标自动放开边界。这次通过的是实现边界和诊断一致性验证，完整实例修复尚未达标。

非目标对象没有丢失原本正确的匹配，也没有发现IoU下降超过1个百分点的对象。
