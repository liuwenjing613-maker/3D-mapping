# 操作和评估审计（2026-10-07）

## 已确认的改善

原 2D CropFormer mask14、24 各自独立，但均被关联至 3D ID52。
联合换票后，ID52 和 ID355 在实际 TSDF 标签上分离，不只是改变显示颜色。
在当前同一 v3 调试适配下：

| 参考目标 | 原预测 ID | 原实例纯度 | 新预测 ID | 新实例纯度 | 新单实例完整 GT 覆盖率 |
|---|---:|---:|---:|---:|---:|
| mask14 / GT4001 | 52 | 48.75% | 52 | 72.49% | 36.56% |
| mask24 / GT4002 | 52 | 50.64% | 355 | 99.94% | 17.71% |

参考目标 GT4002 中归入旧 ID52 的评估参考点从 3501 降到 1236，
有 1683 个参考点进入新 ID355。这支持“局部拆分有效”。仍有 1236 个点在旧实例中，
且 ID52、355 的合计覆盖为 2919 个参考点，低于原来的 3501；完整性损失不能被忽略。
这里的点数是 v3 适配后的参考点，不是原生 PLY 顶点数。

## 操作的范围与不足

2000 个原始帧已全部追踪。最终累加使用原来的 400 个 stride5 建图帧。
210 个存在旧 ID52 家族观察的建图帧中，107 个通过规则，撤回 213 张完整旧观察；
其余 103 个相关帧保留旧证据。本次没有完成全部相关观察的替换。

当前策略要求两个目标在同一帧同时具有可见 seed 锚点并通过门控。
210 个相关帧中有 49 个只满足一个目标至少20个可见锚点的条件。
此外还有追踪不覆盖锚点、超出空间范围、与其他旧实例冲突等失败原因；
不能将这49帧全部假定为可安全替换。后续需要逐对象与逐旧观察匹配，允许可信的
单目标更新，对共同旧观察制定明确的保留/撤回规则。

撤回只覆盖冻结的旧 ID52 家族，不代表其他历史 ID、遮挡后新出现的表面或未识别的
旧观察已全部处理。应审计这些来源，而不是直接扩大空间删除范围。

两组使用同一追踪结果、同一批可靠帧及同一新表面支持。完整400帧重算与增量账本
逐项一致；精确回滚通过；未撤回旧观察支持被保留，干预范围以外原始证据不变。
换票后的后处理仍会改变原始干预范围以外的部分最终标签（整张换票为219点），
不能把“原始证据不变”写成“所有最终标签不变”。

## 当前评分能回答什么

AP50/F1 检验完整实例能否以 IoU>0.5 一对一匹配。新 ID355 的纯度虽高，
完整目标 IoU 只有17.71%，在该规则下仍是 FP。场景 TP=22、FN=25 不变，
FP 从14变为15，因此 F1/AP50 下降；该下降不能单独否认局部合并纠正的效果。
拆分/合并诊断以2cm支持和5%显著交叠门限统计。旧 ID52 仍显著触及两个目标，
GT4002 又显著触及两个预测，所以离散结构计数仍判定残余合并和分裂。
应同时报告纯度、完整覆盖、旧 ID 残留和局部分离量，不能只用一个 PASS/FAIL 概括。

协议文件是 `replica_ca_v3.pending.json`，`frozen=false`。本次运行冻结了具体配置、
代码和输入，但正式 v3 协议本身尚未完成 oracle 校准和冻结。
本次指标均为 `DEBUG_ONLY / NON_OFFICIAL`，不可作为正式实验结论。

## 几何适配限制

评估后的只读诊断发现，在全部固定 TSDF 顶点中，距离完整 GT 椅子表面参考点
小于1cm的比例分别为41.07%、41.05%。该值给出了当前点表示与距离规则下的
理想 IoU 上限；它不等于物理网格缺失比例，也不能仅凭它断定 TSDF 建图错误。
采样、可见性、坐标对齐、重建误差与参考表面范围都需要区分。

两组共用相同几何，因此这个上限可以解释绝对指标较低，不能独自解释修复后
mask24 的 IoU 从27.11%下降到17.71%。后者与旧证据未完整撤回、实例分散和覆盖损失有关。

还确认了一个适配层混杂：`evaluate_pilot_v3.evaluate()` 只将 `instance_id>0` 的
TSDF 点组成预测云，再对参考点搜索最近的已分配点。换票后有些标签变为未分配，
最近邻的候选集合随标签改变。原生几何未变，但参考点的映射与覆盖可能改变；
其对单个目标的影响尚需定量核查，不能提前归因全部评分下降。

建议另加一个事后诊断：对同一完整 TSDF 几何只建立一次最近邻映射，三个版本
使用相同参考支持，再比较标签纯度、交叉污染、未分配率和单实例覆盖。
这只能作为固定表面上的修复诊断；原 v3 分数保留，不通过改门限让试验“通过”。

## 下一步优先级

1. 固定几何支持，量化局部分离改善、旧归属残留与新增未分配点。
2. 逐对象审计未处理相关帧和其他历史观察，补全可信观察的替换与覆盖。
3. 独立核查 TSDF/GT 覆盖、采样及坐标对齐，并在开发场景进行 v3 oracle 校准。
4. 分别报告固定表面标签改善、完整实例质量和非目标实例影响，再扩大到其他案例。

GT 只用于以上事后评估和诊断，不用于本次追踪、筛帧或修复。
