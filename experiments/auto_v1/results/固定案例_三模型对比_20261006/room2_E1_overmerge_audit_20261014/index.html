这次到底筛了什么

规则固定为 n₂ / N ≥ 20% 且 n₂ ≥ 10。N 是 Mask 内全部有效可见的固定 TSDF 顶点数，每个顶点只计一次；n₂ 是其中第二大 CONFIRMED 持久 ID 的点数。U、T、CONFLICT 计入 N，但不当作其他物体。

使用修复前原生状态和持久 ID，复用深度一致性 ≤2 cm 的可见性对应。投影落在同一像素的多个顶点仍分别计数，因此点数不等于图上的像素数。右图仅用于查看这些点的位置。

原图 CropFormer 使用完整原图 Mask；局部 CropFormer 与 SAM2.1 使用上一页可选的完整局部标签区域。SAM2.1 是既有“小区域优先”标签化结果，本次不检查被覆盖的原始重叠提案。触及裁剪边缘会提示，但不会据此剔除。
