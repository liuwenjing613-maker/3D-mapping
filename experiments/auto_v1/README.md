## 暂停时的关键问题与后续要求

旧 E1 的 Gate 仅阻止失败追踪 Mask 直接替换旧观察。后续种子核心／扩展区域仍能修订历史身份，因此“0 帧采用”不等于“未改票”。原流程也可能整张撤销旧观察。这是用户要求改变的行为。

用户已明确：**最终 Gate 通过且实际写入的新 Mask 才能授权对应撤票；仅改该帧新 Mask 覆盖位置的旧票，范围外保留。网页人工检查用于复核，不要求逐帧人工批准后再运行。**

`outputs/e1_auto90_masklocal_20261015/` 目前只有 `mask_local_ops.py` 辅助函数和 `test_mask_local_ops.py` 测试草稿。它们尚未接入 raw replacement、history core、E1 historical revision，也没有在服务器重跑、评分或产生新版 PLY。不可将其理解为限制已经部署。

恢复时依次完成：禁止整观察范围外撤票；核心与扩展历史改票同时约束为同帧、同目标、实际采用 Mask 内的原始采样像素；复用既有追踪，独立目录重放并审计每帧撤票；继续 main R2 成对评价；更新逐帧检查页并明确展示通过／拒绝／实际采用范围。特别检查投影到同一 TSDF 点的多个来源像素，保留范围外来源，区分候选保留与严格投票冲突弃权。

## 归档边界与校验

`publication_manifest.json` 记录每个归档文件的来源、大小、SHA-256。超过 GitHub 单文件限制的三个传输 ZIP 不直接提交；其**所有成员**均保留：与交付页相同的成员引用交付页，已被后来页面覆盖的历史成员放在 `archive_members/`。原 ZIP 哈希也记录在清单。缓存不提交；不包含 SSH 密码、令牌、模型权重或原始数据集。

服务器 SSH 在归档时不可达。仅在服务器保存的完整 2,000 帧原生追踪体积、逐帧投票账本、原生 TSDF NPZ 等未能新增下载；它们的服务器路径与已有哈希保留在冻结记录中。当前分支完整保存**本地已有**的实现与交付结果，不声称是服务器数据盘的完整备份。E1 原始输出路径为 `/data/chenkejun/CVPR/results/e1_auto90_repair_20261015`，代码路径为 `/home/chenkejun/CVPR/experiments/e1_auto90_repair_20261015`。

实现文件保留实际运行时的服务器绝对路径；这是可审计快照，不是已完成路径迁移的跨机器安装包。原始模型、数据集和 Python 环境仍需按配置准备。
