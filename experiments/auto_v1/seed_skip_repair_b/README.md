## 已确认规则

用户确认：只用种子来源帧；两个覆盖率均 ≥95% 就跳过；冲突数量仅展示。没有第二帧复核、最小支持点门槛或冲突否决条件。

- S：原始种子 Mask 内、来源帧可见的唯一固定 TSDF 点，包括未分配点。
- I：与 S 交集最大的正实例 ID 在该帧的全部可见点，不能把 I 裁进种子内部。
- p = |S∩I| / |S|，r = |S∩I| / |I|。两项同时达标才跳过，用整数比较 20×交集 ≥19×分母避免阈值舍入。
