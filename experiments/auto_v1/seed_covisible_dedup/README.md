## 固定规则

设 A、B 为原始完整 Mask 在各自来源帧中的固定 TSDF 支持点集合。A' = A ∩ Visible(frame_B)，B' = B ∩ Visible(frame_A)。S = |A' ∩ B'| / |A' ∪ B'|。双方各自可见比例 ≥ 0.30、可见点数 ≥ 20 且 S ≥ 0.80 时才通过去重判据；否则继续保留。判据使用整数交叉相乘，阈值均包含等号。

可见性完全沿用原先 project_visible：相机深度在 0.05–10 m 内，投影四舍五入，深度反投影点与相机坐标三维点距离 ≤ 0.02 m。47 帧缓存均独立复算，72 个支持点集合均从原 Mask 重新验证。比较的是固定点索引，不进行近邻匹配或栅格膨胀。

按完整原始支持点数降序选择固定代表；并列依次按帧、来源模型编号和原 Mask 摘要排序。只有与代表直接通过判据的种子才退出最终执行清单，不传递合并。原 Mask、稀疏原编号和辅助候选来源均保留在审计资料中。导出 seed_manifest.json 仅含保留的 70 个原主种子，未将被删主种子的旧辅助候选自动升级或合并。新辅助观察关联另见 dedup_groups。
