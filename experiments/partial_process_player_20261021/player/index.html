partial：只撤除实际采用 Mask 覆盖、且原身份属于该种子 old_family 的观察。其他身份候选保留；同帧同点多个不同 ID 会整点弃权，得到 0 张有效票。原观察像素数、候选数、有效票数是三个不同的量。

三个阶段：直接替换 → 原有核心历史修订 → 原有 E1 历史修订。每阶段400帧：0、5、…、1995。阶段切换保持源帧号。累计票数从完整基线开始按阶段重放；不是在线建图前缀。

图层：“新 Mask”是通过门控的实际采用结果；“原观察像素”在直接阶段显示被撤除的原 Mask，在历史阶段显示实际改写的投影采样像素。有效票图只绘制当前事务相关的点，不是整幅图的最终分割。

点的累计身份：领先票≥2且占比≥67%才确认；本页也列出已保存终态的后处理标签，二者分开。逐帧一致性通过不等于每个对象的修复质量改善。
