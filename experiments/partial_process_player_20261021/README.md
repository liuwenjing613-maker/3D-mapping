# 当前 partial：room0 / room1 逐帧查票

按用户要求提供自动196、人工76两组的 room0 和 room1，共四组真实 partial 事务。每组分别回放直接替换、原核心历史改票、原 E1 历史改票，每阶段400帧（0、5、…、1995），共4800条事务。本次仅导出检查材料和实现只读播放器，没有新增保护规则或修改任何算法、门控、关联与评分结果。

## 打开与观看

本地完整交付目录：`CVPR/results/partial逐帧检查器_20261021`，双击 `打开检查器.cmd`。默认打开人工 room1 枕头帧390；可切换四组、所有修复对象和三个阶段。左图为原观察证据，右图可切换有效票变化、新 Mask、撤除/改写的原观察像素。滚轮和拖动同时控制两张图。

点选图像或表格后，右侧显示同一 TSDF 点的前后候选、本帧有效票、累计账本和全部改票历史。方向键逐帧往返，Shift＋方向键跳到所选对象/区域的下一次变化；时间轴支持拖动、直接输入帧号。A–B循环和本机书签保存回看位置、区域、缩放。当前帧点表支持筛选和 CSV 导出。

内置插座GT44/56/80、枕头GT9、书本GT85的事后定位范围，只用于人工查找。GT范围来自此前冻结结果的 main R2 对应索引，不参与候选重建、改票或任何在线判断。

## 数据含义与核验

回放从完整400帧基线出发，按阶段、帧号重放已保存事务，**不是在线建图前缀**。历史阶段沿用原核心/E1规则。累计原生身份采用原阈值（领先票≥2，领先占比≥67%），保存的终态后处理标签单独列出。

三阶段的全量账本、原生标签及状态逐点精确匹配归档输出；倒放精确恢复基线。每帧重新定位原观察采样像素，并与保存的候选集合、严格一票弃权结果逐一核对。浏览器测试覆盖四组、阶段切换、点锁定、前后恢复、键盘、A–B循环、同步缩放和书签；候选检查及浏览器证据见 `evidence/qa_engine.json`、`evidence/qa_browser.json`。这些核验只证明回放正确，不代表修复质量改善。

原始RGB保留1200×680。有效票变化标记是TSDF点重投影，只有通过2cm深度可见性检查才画在图上；完整点记录仍在表格。直接撤除图层是实际原Mask撤除区域；历史图层是实际改写的采样像素。没有伪造未保存的中间地图。
