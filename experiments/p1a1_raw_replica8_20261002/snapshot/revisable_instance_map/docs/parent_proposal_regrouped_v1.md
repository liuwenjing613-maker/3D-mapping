# 无修复基础架构改进：来源归组的几何证据（room0，400 帧）

## 设计结论

对象产生与跨帧关联以原始 CropFormer 提案为单位。OVI-MAP 深度几何结果作为可编辑子区域证据；每个像素的真实来源由原始 mask 与细化 mask 逐像素相交确定，不能直接把细化区域 `cropformer_id` 当来源。默认无修复地图只用细化区域中具有原始 CropFormer 来源的像素，并按该来源重新归组；被细化删去的原始像素、原始背景被细化吸收的像素均保留在不可变输入和来源账本中，供后续修订使用。

数据流：原始 RGB-D/位姿/CropFormer mask + OVI 几何 mask → 逐像素来源账本 → 来源归组 mask → 全帧旧状态关联 → 每观测 3 cm 支持账本 → 共享 1 cm TSDF 表面的实例投票。GT 仅在最后的离线评估读取。

## 已实现

- `tools/build_parent_child_lineage.py`：记录全部 12,046 个原始提案与几何子区域的 41,996 个精确交集；原始像素中 9,895,513 个是细化残留，原始背景中 1,141,788 个被细化吸收，另存在 9,798 个背景与细化区域交集。原始/细化 PNG 与每帧 SHA-256 是逐像素重建的权威来源。
- `tools/build_refined_parent_masks.py`：按**真实原始像素 ID**归组细化正区域。生成 11,729 条有效提案；317 条原始提案完全不在细化正区域内，总共 97,364 个原始像素，仍留在来源账本，当前地图不强行给它们新对象 ID。
- `association.py`：同一持久实例可在同一帧接收多个原始提案，整帧先对旧地图打分后统一提交；增加可选的候选回退、有效深度优先采样及原子身份重分配。每观测 3 cm 支持体素和当前 ID 单独保存到 `observation_support_3cm.npz`，索引可由它重建。
- `materialize_instance_map.py`：增加有效深度优先采样和按帧/体素/实例去重投票选项。1 cm 实例表面始终从来源观测与当前关联重建，几何 TSDF 不因实例 ID 改变而重融。
- `tools/remap_parent_associations.py`：保持原始关联 ID 不变，只替换细化归组像素，隔离边界证据作用。

同一 Replica room0 的 400 帧、同一共享 TSDF、同一 Replica-CA-v1 离线协议与 GT。这里的 CA-AP50 是自定义类别无关指标，不是官方 ScanNet AP。

## 解释与默认配置

细化区域 `cropformer_id` 与真实原始来源不一致的像素共 11,291,651 个。逐子区域建对象和单区域约束导致明显过碎。来源归组后重做跨帧关联获得最高指标；固定原始关联仅替换边界反而下降，说明收益来自清理来源后的跨帧重解释，而非单独裁边。候选回退使原始输入的 8,145 条决策改变，但 room0 指标下降；有效深度优先采样单独运行时全部 12,046 条实例 ID 不变。因此默认采用来源归组 + 同帧多区域关联，不启用候选回退。有效深度优先与帧级投票去重可作为结构上更稳的实现选项，本场景指标基本不变。

`/data/chenkejun/CVPR/revisable_instance_map/` 下保留所有输入目录、关联表、支持账本、实例表面、离线预测、指标和日志。推荐主结果为 `association_ovimap_parent_regrouped_multi/`、`map_ovimap_parent_regrouped_multi_vf_dedup/`、`evaluation_ovimap_parent_regrouped_multi_vf_dedup/`；原始输入稳健对照为 `association_parent_raw_multi_final/` 与 `evaluation_parent_raw_multi_final_vf_dedup/`。

## 当前边界

这些结论只在 room0 上验证，不能据此宣称跨场景最优；下一阶段需固定配置后在其他场景检验。3 cm 关联支持索引与 1 cm 表面投票仍是两种分辨率，虽然二者都能从观测与关联重建，但尚未共用同一缓存。身份重分配已有原子重建接口；mask 内区域改写、自动冲突检测与历史修复尚未实现。前端 CropFormer/OVI 推理时间不在本次无修复建图计时内。

完整官方 OVI-MAP 管线的既有 room0 诊断结果为 CA-AP50 0.3732、CA-PQ 0.4430；它同时更换了后端与几何组织，只能作为性能参照，不能用于归因本次前端/关联消融。
