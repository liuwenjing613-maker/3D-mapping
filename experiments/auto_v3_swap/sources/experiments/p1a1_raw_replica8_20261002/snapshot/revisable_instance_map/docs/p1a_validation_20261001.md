### 结构与限制

| 输出 | 关联 | 显著过拆分 GT 数 | 显著过合并预测数 | 诊断预测数 |
|---|---|---:|---:|---:|

| 原生 P0 | 概率 | 71 | 64 | 270 |
| 同一扩散 | 二值 | 70 | 67 | 298 |
| 同一扩散 | 概率 | 74 | 66 | 270 |

整体指标提升，但结构错误没有全面改善。概率版新建 ID 更多；其中很多没有形成最终有效发布实例，不能把累计 ID 数直接当作有效物体数。过合并预测的绝对数量略降，因诊断预测总数也减少，其比例反而上升。过拆分 GT 数略增，需要后续讨论门控，不能只凭 AP50 宣称解决了身份错误。

受控测试中，已有九帧正确书实例支持、大物体历史更长，注入一次错误书→桌子关联后，原二值策略的后三条观测继续跟随错误 ID；概率支持策略的后三条恢复到已有书 ID。原错误观测仍未自动迁移。另一项持续错误、没有独立正确假设的测试明确保留失败，不假设概率累计必然自愈。

本轮未调整阈值，未启用 P1-B 的暂定隔离，未加入新去噪。首版可作为计票与概率评分的独立对照，后续讨论应同时关注阈值分布、过拆分与小物体召回。
