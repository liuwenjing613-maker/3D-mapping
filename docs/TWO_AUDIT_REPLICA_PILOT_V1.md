## 沿用已确认的三个环节

1. 原始观测缓存：固定检查点的有序 TSDF 表面、原始 CropFormer Mask、深度和相机。深度一致阈值 0.015 m；记录所有有效可见点，包括背景。不同几何空间不能复用点索引。
2. 稳定簇：双方共同可见支持各至少 25 点、IoU 至少 0.55；固定首个有效代表、同帧唯一、多簇匹配歧义暂缓；至少 3 个不同帧和 2 个视角组才稳定，视角差异为平移 0.1 m 或光轴 10°。
3. 只读异常审查：同一帧不同原始 Mask、属于两个已归属稳定簇、在同一旧 ID 上双方各至少 25 点；同一对簇及旧 ID 的分离在至少两个独立共同视角复现。输出疑似过合并和精确 ROI 核心/周边覆盖，不增加覆盖比例门槛，不触发修复。

三个环节的算法代码和参数均未因数据集切换而修改。输入检查证明现有适配器可直接读取 Replica 原始 Mask、位姿、固定内参、几何证书及原始 ROI 来源。

值得优先人工查看的较高覆盖例子：
